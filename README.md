Call Center Performance Dashboard

Project Overview

This project is a Call Center Performance Dashboard created in
Microsoft Excel to analyze employee working hours, attended call
percentage, total break time, and non-working time during calls.

The dashboard converts call center employee data into simple visual
reports that help understand employee performance and identify areas
where productivity can be improved.

Dashboard Reports

The dashboard contains four main reports:

1. Working Hours

Shows the total working hours recorded for each employee.

Key metric: - Total Number of Working Hours

2. Attended Call Percentage

Shows the percentage of calls attended by each employee.

Key metric: - Attended Calls Percentage

3. Total Break Taken

Shows the total break time taken by each employee.

Key metric: - Total Break Taken

4. Not Working During Call

Shows the percentage of time employees were not working during calls.

Key metric: - Not Working During Call Percentage

Call attendance

Break duration

Overall employee productivity

These comparisons can help managers identify high-performing employees,
unusual break patterns, and areas that may require attention.
